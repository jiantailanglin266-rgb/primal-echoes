# BALANCE

調整値の記録。値そのものは `src/data/*.json` が正で、本書は **「なぜその値か」** と変更履歴を残す。

## 原則
- コードに Magic Number を書かない。すべて data 化する。
- 変更時は「変更前 → 変更後 / 理由 / 検証方法」を残す。
- 目標体験: 初見 Valgaron 討伐 **15〜20 分**、慣れたプレイヤーで **8〜12 分**。

| Rock Throw | 30 | 0.80 / 0.60 / 0.10 / 1.30 | middle, far | 正面 ±0.7rad | 5s | 3 | 3.0m | 水平速度 20m/s の放物線。胸の高さを狙うので歩きでは避けられず、回避か横移動が必要 |

- 全攻撃に telegraph ≥ 0.5 秒。プレイヤーの回避（無敵 0.04〜0.32 秒）で「見てから」抜ける余地を必ず残す。
- 被ダメージ = 威力 × 100 / (100 + 防御)。防御 0 の初期状態で 3〜4 発で戦闘不能。防具（T15〜）で伸ばす。
- クールダウンは攻撃**終了**から数える（開始から数えると攻撃時間より短い値が意味を持たない）。
- 攻撃間隔 0.6〜1.8 秒（乱数）。この間は向き直りと接近だけを行う。
