# BALANCE

調整値の記録。値そのものは `src/data/*.json` が正で、本書は **「なぜその値か」** と変更履歴を残す。

## 原則
- コードに Magic Number を書かない。すべて data 化する。
- 変更時は「変更前 → 変更後 / 理由 / 検証方法」を残す。
- 目標体験: 初見 Valgaron 討伐 **15〜20 分**、慣れたプレイヤーで **8〜12 分**。

## 通しプレイ検証（T20, 2026-09-05）
検証方法: `?bot=1` の PlaytestBot（側面へ回り込み、判定 0.2 秒前に回避、隙に弱攻撃、HP 45% 未満で離れて活性薬、討伐後に剥ぎ取り）を `GameManager.update` で早回し。25 分上限。

| 回 | 条件 | 結果 | 討伐時間 | 命中 | 与ダメ | 被ダメ | 力尽き | 出来事 |
|---|---|---|---|---|---|---|---|---|
| 1 | 初版（威力 +4、回復なし、正面から殴る素朴ボット） | 失敗 | - | 90 | 1593 | 361 | 3 | 63s 怒り、64s 頭破壊。3 分で 3 乙 |
| 2〜4 | 威力 -4、活性薬 ×5、回避タイミング修正前 | 失敗 ×3 | - | 105〜165 | 1715〜2853 | 575〜610 | 3 | 1 回目は 314s に逃走→巣で睡眠まで到達 |
| 5〜7 | 上記 + 回避を判定 0.2 秒前に + 側面取り | 成功 ×3 | 868 / 905 / 916 s | 175〜186 | 3300〜3342 | 0〜62 | 0 | 頭・両前脚破壊、680s 前後で逃走→睡眠→寝込みで討伐 |

所見:
- 「予備動作を見てから正しいタイミングで転がる」「正面に立たない」の 2 点で被ダメージが 600 → 0 になる。設計意図（観察→予測→回避→反撃）どおりに難易度が生まれている。
- 慎重プレイで約 15 分は長いので HP を 2800 に下げた（-12.5%）。
- 逃走→睡眠→寝込みを襲う流れが毎回発生し、討伐の締めとして機能している。
- ボットは尾を狙わないため尾切断は未検証（単体テストでは検証済み）。
