## 2. 診断

### 2.1 「一流の作品に見えない原因」トップ 10（影響度順）
| # | 原因 | 理由 |
|---|---|---|
| 1 | **タイトル画面が無く、起動直後に管理画面** | 作品の「第一幕」が存在しない。世界に入る前に表を見せられる |
| 2 | **ロゴ・シンボルが無い** | 記憶に残る形が無い。ローディングの文字列は書体が OS 依存で環境ごとに変わる |
| 3 | **書体が OS 依存** | 統一された「声」が無い。Windows と Mac で別のゲームに見える |
| 4 | **固有名詞の語感が揃っていない** | 英語ファンタジー（Titan Blade）、和製漢語（翠嵐峡谷）、軍事英語（SURVEY STATION）、一般名詞（森林・川）が同居 |
| 5 | **タイトルと世界観が結びついていない** | 「残響（Echoes）」が世界のどこにも出てこない。エーテルは汎用語で、作品固有の概念が無い |
| 6 | **音がすべて電子音、BGM 無し** | 質感の 8 割は音。合成矩形波は「試作品」の印象を決定づける |
| 7 | **文章が管理・技術の言葉** | 「シェーダをコンパイル」「記録を消去しますか？」は世界の外の言葉。感嘆符が軽い |
| 8 | **画面の余白と階層が管理画面的** | 拠点は情報を並べた表。見せ場（獣の名前・討伐時間）に大きさの差が無い |
| 9 | **アイコン・装飾・質感が無い** | 罫線と半透明パネルだけで、世界の素材（石・遺物・革）が UI に無い |
| 10 | **対外資産ゼロ** | favicon / OGP / スクリーンショットが無く、共有された瞬間に「未完成」と判断される |

### 2.2 一貫性が崩れている箇所
- 和名の地形（翠嵐峡谷）× 英語軍事見出し（MISSION COMPLETE / SURVEY STATION）。
- 武器名・技名は英語のみ、素材名は日本語のみ、強化名は `英名 — 和名` の混成。
- モンスターの和名が JSON に無く、コードに散在（QuestManager / items 説明）。改名すると 3 箇所を追う必要がある。
- 拠点の呼称が「ベースキャンプ」（キャンプ）と「SURVEY STATION」（施設）で二重。
- 通知の口調: 「雨が降り始めた」（描写）と「気絶！」（叫び）と「任務開始: 〜」（システム）が同じ場所に出る。
- 品質自動降格の通知（「描画品質を mid に下げました」）が世界の中に出る。

### 2.3 すでに強みになっている要素（残す）
- **タイトル `PRIMAL ECHOES`** 自体。語感が良く、意味付け次第で世界観の核になる。
- **翠嵐峡谷** という和名の型（二字熟語＋地形語）。作品固有の「和名の型」の起点になる。
- **ヴァルガロン / Valgaron、グラスト、スカルヴ** の語感。カタカナ 4 文字・濁音の重さが揃っている。
- **「生態を理解することが攻略になる」** という設計思想。ブランドの中心に据えられる。
- 金 `#d8b26a` × 暗い背景の抑制されたパレット。方向は正しい（拡張が必要なだけ）。
- 斬れ味の 1 字表記「鈍・並・鋭・冴」。簡潔で世界に合う。
- 空・霧・雨の連動、肩越しカメラ、スローモーションなど CG 側の「重さ」。ブランドが追いつけば釣り合う。

## 3. ブランド設計の論点：独自ポジション 3 案

| 案 | ポジション | 差別化点 | 実装コスト |
|---|---|---|---|
| **A（推奨）** | **「世界の記憶を聴く狩猟叙事詩」** — 生体エネルギーを「残響（エコー）」と定義し、獣は原初の時代の残響そのもの。狩人は痕跡を「聴く」者 | タイトルと世界・システム（観察＝攻略）が一本の線でつながる。競合の「素材集めのための狩り」に対し「世界を読む狩り」を打ち出せる | 中。用語の置換（エーテル→残響）、テキスト全面改稿、ロゴのモチーフ（波紋・地層）に直結 |
| B | 「調査記録としての狩猟」 — 図鑑・記録・観察に軸足。ドキュメンタリー調 | 静かで知的。UI を「調査手帳」に統一しやすい | 中〜高。図鑑・記録システムの拡充が必要で、戦闘の重さが後景に退く |
| C | 「文明の残骸と獣」 — 遺跡・遺物を前面に、失われた文明の謎を追う | 世界の謎で牽引でき、ローディングの断片テキストが活きる | 高。遺跡フィールドや遺物アイテムなどコンテンツ追加が前提 |

推奨は **A**。既存の資産（タイトル、観察の設計思想、地形名の型、カタカナの獣名）をすべて活かせ、追加コンテンツ無しでブランドの芯を通せる。B の「記録」と C の「断片テキスト」は A の中に要素として取り込む。

以降の B1 は案 A で設計する。
