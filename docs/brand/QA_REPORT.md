## 4. 細部
| 項目 | 結果 |
|---|---|
| フォント読み込み失敗時 | `tokens.css` のスタック（Times / 游明朝 / Hiragino Mincho / Georgia）へ落ちる。`display=swap` で白画面にならない。ロゴは SVG のアウトラインなのでフォント非依存 |
| テキストのはみ出し | 幅 800 と 1280 でメニュー・設定・前哨（1 列化）・討伐画面・HUD を目視確認。英語は日本語より長い箇所（`Retreat after {n}`、`Time to the kill`）があるが、いずれも折り返しで収まる。※ 隠れたブラウザペインでは幅 0 になるため機械測定は不能。実ブラウザでの再確認を推奨 |
| 英語モードの表示崩れ | メニュー・設定・前哨・HUD・討伐画面を英語で確認。数値のフォント（Cormorant）は英数で共通 |
| 音の途切れ・フェードの重なり | BGM は 1 曲・4 層で場面を渡るので切れ目がない。画面遷移の 320ms フェードと音のフェード（0.6〜5 秒）は独立。同一 SE は 30〜100ms で間引き |
