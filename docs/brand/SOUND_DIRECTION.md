# PRIMAL ECHOES — SOUND DIRECTION（B6）

前提: `BRAND_BIBLE.md`（畏怖 / 痕跡 / 静寂。「重く、短く、静かに」）。実装は `src/audio/`。

---

## 1. 方向性

### 1.1 BGM — 環境音主体、旋律は控えめ
- 曲は 1 つ。**切り替えず、4 つの層の音量で場面を渡る**。
  | 層 | 内容 | 探索 | 戦闘 | 討伐 | タイトル |
  |---|---|---|---|---|---|
  | bed | 風のような低いノイズ＋ A1（55Hz）のドローン | 0.7 | 0.45 | 0.8 | 0.9 |
  | pulse | E1（41Hz）の三角波が 0.9 秒周期で脈打つ | 0.2 | 0.6 | 0 | 0.15 |
  | strings | E2 / B2 の鋸波を強くローパスした低音弦 | 0 | 0.4〜0.7 | 0.5 | 0.25 |
  | drums | 皮の太鼓（低い正弦波の落ち＋短いノイズ）、BPM 72、2 小節パターン | 0 | 0.35〜0.8 | 0 | 0 |
- 戦闘の激しさ（heat、怒りで 1）で strings と drums が段階的に重なる。
- フェード: 探索→戦闘 2.5 秒、戦闘→探索 5 秒（すぐには安心させない）、討伐 0.6 秒で静める。
- 旋律を入れるなら 1 モチーフだけ（サウンドロゴの 3 音: G3 → D4 → G4 の上昇）。

### 1.2 SE — 石・骨・革
- 金属的な高音を避ける。**ローパス／バンドパスしたノイズ＋低い正弦波**で作る。矩形波は使わない（テストで禁止）。
- ヒットは重く短く: 軽攻撃 0.09 秒、重攻撃 0.28 秒（40Hz の落ち）。部位破壊は「石が割れる」帯域（300〜1400Hz）＋ 40Hz。
- UI は乾いた小さな「こつ」（バンドパス 2kHz、40ms）。ホバーはさらに小さく（25ms）。
- 同じ音は ±3〜12% のピッチ揺らぎで連続感を消す。30〜100ms 以内の連打は間引く。
- 咆哮は 1.1 秒。低い鋸波（62→84Hz）＋ローパスのノイズ。画面の色収差パルスと同期する。

### 1.3 環境音 — エリア別ループ
| エリア | 風 | 虫 | 水 | 洞 |
|---|---|---|---|---|
| 前哨 | 0.35 | 0.2 | | |
| 苔の谷底 | 0.45 | 0.5 | | |
| 白瀬 | 0.3 | 0.15 | 0.7 | |
| 獣の寝床 | 0.12 | | | 0.6 |
- 雨: 雨音（ハイパス 2.4kHz）を足し、虫を黙らせ、風を強める。洞の中では雨音を遠く（0.25）。
- 前哨画面・タイトルでは環境音を静め、BGM の bed だけを残す。

### 1.4 サウンドロゴ（2 秒）
- 低い「どん」（48→44Hz）＋ ローパスのノイズ → 残響の環のように上へ薄れる 3 音（G3 / D4 / G4、遅れて重なる）。
- タイトル画面でロゴが出た瞬間に鳴る。ローディングの環が満ちる演出と同じ「内から外へ」。

### 1.5 無音でも成立させる
- すべての音の合図には視覚の手応えがある: ヒット（Hit Stop・火花・数字）、部位破壊（バナー・シェイク）、咆哮（色収差・シェイク）、気力切れ（バーの色）、討伐（スロー・バナー）。
- 音量 0 でも進行に必要な情報を音だけで伝えない。

## 2. 実装（`src/audio/`）
| ファイル | 役割 |
|---|---|
| `AudioEngine.ts` | AudioContext、バス（music / sfx / ambience → master）、初回操作での unlock、素材の読み込み（無ければ null） |
| `synth.ts` | ノイズ層・正弦波層、ループ（風・ドローン・素材）、フェード |
| `Sfx.ts` | 効果音 17 種の定義（合成レシピ＋素材名＋ピッチ揺らぎ＋間引き）。素材があれば素材、無ければ合成 |
| `Music.ts` | `layerTargets()`（場面→層の音量、純関数）、レイヤー再生、合成の打楽器の先読み予約 |
| `Ambience.ts` | `ambienceTargets()`（エリア・雨→層の音量、純関数）、ループ、合成の虫 |
| `AudioManager.ts` | 窓口。`play` / `playLogo` / `setMusic` / `setMusicHeat` / `setAmbience` / 音量 3 系統 / `update` |

GameManager からの接続: タイトル・メニュー = `title`、前哨 = `explore`（環境音は静音）、狩り中は獣を認識していれば `combat`（怒りで heat 1）、討伐で `resolve`、帰還で `explore`。エリアと雨は毎フレーム `setAmbience` へ。

## 3. 素材ファイルの置き場（任意）
`public/assets/audio/` 以下に置くと自動で合成音から差し替わる（無ければ何もしない）。すべて CC0 または商用可を確認し、README の出典欄に記す。

| パス | 内容 | 目安 |
|---|---|---|
| `bgm/bed.ogg` / `pulse.ogg` / `strings.ogg` / `drums.ogg` | 同じテンポ・同じ長さのループ 4 本（BPM 72、2〜4 小節） | 各 30〜60 秒、-14 LUFS |
| `amb/wind.ogg` / `insects.ogg` / `water.ogg` / `rain.ogg` / `cave.ogg` | 環境音ループ | 各 20〜40 秒、継ぎ目なし |
| `sfx/hit_light.ogg` … `sfx/logo.ogg` | `Sfx.ts` の `sample` 名 | 単発、頭の無音なし |

入手先の例: freesound.org（ライセンス CC0 で絞る）、pixabay.com/sound-effects、opengameart.org。ループは Audacity でクロスフェードして継ぎ目を消し、`ffmpeg -i in.wav -c:a libvorbis -q:a 4 out.ogg` で変換する。
