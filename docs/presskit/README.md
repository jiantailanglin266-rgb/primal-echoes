# PRIMAL ECHOES — プレスキット

## 作品概要
**PRIMAL ECHOES（原初の残響）** は、ブラウザで遊べる 3D 狩猟アクション。海図の外の大陸ヴァルディアで、狩人は痕跡を読み、原初の残響を宿す巨大な獣「原獣」と向き合う。獣の生態（捕食・飲水・睡眠・雨の退避・負傷時の帰巣）を理解することが、そのまま攻略になる。

- タグライン: **原初は、まだ鳴っている。** / *The first world still echoes.*
- ワンライン: 痕跡を読み、原初の獣と向き合う。 / *Read the traces. Face the first beasts.*
- プレイ: https://jiantailanglin266-rgb.github.io/primal-echoes/
- リポジトリ: https://github.com/jiantailanglin266-rgb/primal-echoes

## 特徴
- **観察が武器になる**: 足跡、食い荒らされた草、雨。獣の行動には生態上の理由があり、読める。
- **重く、短い戦闘**: 攻撃には発生・判定・硬直がある。Hit Stop、スローモーション、部位破壊。
- **一貫した世界**: 残響（エコー）という一つの概念で、タイトル・獣・素材・鍛冶がつながる。
- **無料・インストール不要**: URL を開くだけ。端末に応じて画質が自動で決まる。
